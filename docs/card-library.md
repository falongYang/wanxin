# 共同经历搜索与月份回看

项目经理已确定本轮范围，直接本地实施，不引入依赖或改变服务接口。沿用夜色与信笺样式。

## 设计

列表头部提供带标签的搜索输入、清空按钮和结果数。只对现有已加载卡片标题/正文做trim、转小写后的连续子串匹配；查询也trim并转小写，空查询显示全部，不分词、不把标题与正文拼接匹配。输入值仅React内存，不写URL、持久存储、日志或API参数。

以createdAt的Asia/Shanghai自然月分组；组按月份倒序，卡片按createdAt时间戳倒序，同时间按id字典序升序保证刷新/输入顺序变化仍稳定。列表日期也使用上海时区。服务端正常返回有效日期；异常日期作为“日期未知”置后，避免页面崩溃。

空收藏提示如何保存；有收藏但搜索无匹配提示没有结果，并提供清空。清空后焦点回搜索框。已有加载/错误及准入恢复机制保留。

打开详情前在内存保存列表window滚动位置、卡片ID和显示序号；返回时刷新卡片，保留查询，恢复滚动并聚焦新DOM中的原卡片。编辑/删除导致该卡不再可见时，聚焦最近仍在的卡片；无匹配则聚焦搜索框并回到列表顶部。内容变短时滚动自然钳制。清除整个会话时重置搜索与返回状态。搜索本身不请求网络；详情/返回仍沿用现有API。

## 验收

- 纯函数回归中文、英文大小写、前后空白、空查询、无匹配、标题/正文隔离、UTC转上海跨月、倒序与同时间ID排序；不修改传入数组。
- 静态隔离构建+合成HTTP：搜索不发请求/不持久化，键盘搜索与清空，详情返回原查询/滚动/焦点，编辑不再匹配及删除后结果更新，空收藏与无结果区别；续聊载入最新引用且不自动发、来源准确或缺失提示。
- 320×740、390×844、1280×900截图核对，无横向溢出、操作可达。合成HTTP结果不证明真实模型/后端全链路或真机。
- 新增源码/测试/脚本/本文入候选白名单。旧验收保留为历史，旧摘要不当作本轮；新临时副本npm ci/测试/构建，重新记录源码/产物SHA256。已有准入改动、共享依赖、数据库及服务不动。
